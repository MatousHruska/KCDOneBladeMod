OneBlade Mod for Kingdom Come: Deliverance II v1.5.2
====================================================

INSTALLATION
------------
1. Copy the entire "oneblade" folder to your KCD2 mods directory:
   [Steam]\steamapps\common\KingdomComeDeliverance2\mods\

2. The folder structure should be:
   mods/oneblade/mod.manifest
   mods/oneblade/Data/...
   mods/oneblade/Localization/...

3. Launch the game.


ADDING ONEBLADE TO YOUR INVENTORY
---------------------------------
To add the OneBlade sword via console command:

1. Enable developer mode:
   - Right-click KCD2 in Steam -> Properties -> General
   - Add "-devmode" to Launch Options (without quotes)

2. In-game, press the tilde key (~) to open the console

3. Type the following command:

   wh_cheat_addItem fd0db742-6c8c-475e-983f-1594f99fc904

4. The OneBlade will be added to your inventory
